# /standards — authoritative source documents (PDF)

Place the official regulation **PDF** files here. The citation system
(`docs/citation_system.md`) reads requirements **directly from these PDFs**.

- Only authoritative source PDFs belong here.
- No YAML/derived regulatory database is used anymore.
- Until PDFs are added, the regulatory knowledge base is **empty** and every
  requirement resolves to: "Source document required for verification".
